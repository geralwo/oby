# oby

oby is a small selfcontained scripting environment with a strong core library.
Its static typing makes errors easy to catch and the lean and concise syntax make it
comfortable to use. 

## Hello example
```
str = "Hello World!\n"
print(str)
```

## Versioning

`0.x` semver: a **minor** bump marks a milestone, or a change that can break an
existing script; a **patch** bump is fixes and additions that cannot. `1.0`
waits for the deferred features (sum types and traits, the memory story) and a
frozen syntax.
